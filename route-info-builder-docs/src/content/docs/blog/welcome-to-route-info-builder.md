Welcome to the official blog for **Route-info-builder**!

## What is Route-info-builder?

Build-time route scanner for Axum-like frameworks: type-safe Rust link enums, TypeScript clients with TanStack Query hooks, OpenAPI 3.1 skeletons and JSON route maps.

## What to expect here

This blog is the central hub for everything related to Route-info-builder. We will be publishing:

- **Deep dives** into the architecture, design decisions, and inner workings of the project.
- **Tutorials and how-to guides** to help you get up and running quickly.
- **Release notes** and feature announcements as the project evolves.

Whether you are just discovering Route-info-builder or have been using it for a while, we are glad you are here. Stay tuned for our first official deep dive!
