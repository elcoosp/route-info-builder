This page describes the `route-info-builder` command-line interface. The binary ships as the crate's default `cli` feature; building the crate with `default-features = false` omits it. `--version` reports the crate version (`propagate_version` is enabled).

## Commands

| Command | Purpose |
| :--- | :--- |
| `route-info-builder generate [flags]` | Generate the Rust link enum and every configured output. |
| `route-info-builder scan [flags]` | Print the scanned route map as JSON to stdout. |
| `route-info-builder init [path] [--force]` | Write a starter `route-info.toml`. |

`generate` and `scan` accept the same flags.

## Flags of `generate` and `scan`

| Flag | Type | Overrides |
| :--- | :--- | :--- |
| `-c, --config <path>` | path | Configuration file used instead of the default lookup. |
| `--controllers <dir>` | path | `controllers_path`. |
| `--rust-output <file>` | path | `rust.output_file`. |
| `--ts-dir <dir>` | path | `typescript.output_path`; implies `generate_client = true` for this run. |
| `--openapi <file>` | path | `openapi.output_path`. |
| `--route-map <file>` | path | `route_map.output_path`. |

Overrides apply for the current invocation only; the TOML file is not modified.

## `generate`

Loads the configuration, applies flag overrides, scans the controllers and writes every configured output, creating parent directories. Prints a summary listing each written artifact:

```ansi
Generated Rust link enum (2413 bytes).
  rust:      src/generated/links.rs
  typescript: frontend/src/api/client.ts
              frontend/src/api/api.ts
  openapi:   openapi.json
  route map: routes.json
```

Lines appear only for outputs that are configured (or overridden).

## `scan`

Loads the configuration, applies flag overrides, scans the controllers and prints the JSON route map — pretty-printed, one record per route — to stdout. Nothing is written to disk.

## `init`

| Argument / flag | Type | Default | Effect |
| :--- | :--- | :--- | :--- |
| `path` | positional | `route-info.toml` | Where the starter configuration is written. |
| `--force` | flag | — | Overwrite an existing file. |

Without `--force`, `init` refuses to overwrite an existing file with `refusing to overwrite <path> (pass --force to overwrite)` and exits `1`. The starter content matches the default configuration file name and covers `controllers_path`, `[rust]`, `[typescript]`, `[openapi]` and `[route_map]`.

## Default configuration lookup

With no `--config` flag, both `generate` and `scan` use `route-info.toml` in the working directory when it exists and fall back to built-in defaults otherwise. An explicit `--config` path that does not exist is an error.

## Exit codes

| Code | Meaning |
| :--- | :--- |
| `0` | Success, including `--help` and `--version`. |
| `1` | Runtime failure: unreadable paths, invalid TOML, invalid Rust, unwritable outputs. The CLI prints `error:` followed by a `caused by:` chain. |
| `2` | Usage error: unknown flag, missing subcommand, unparsable arguments. |

<Aside type="caution">
  Exit code `2` is reserved for argument-parsing failures. Scripts that distinguish "wrong invocation" from "generation failed" should match on that code.
</Aside>
